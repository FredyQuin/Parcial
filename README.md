# Gestor de Préstamos de Biblioteca - MVP

Proyecto académico. Ciclo de Vida Ágil usando Notion, Trello, Jira y GitHub.

## Tecnologías
- HTML + JS básico (frontend)
- Pseudocódigo en /backend
- GitFlow para control de version

## Flujo de desarrollo
1. Ramas feature por historia de usuario.
2. Commits referencing Jira issues (ej: LIB-3 #done).
3. Pull Requests revisados por compañeros.

## Estructura
/frontend -> interfaz básica  
/backend -> pseudocódigo 
/docs -> evidencias (capturas)
